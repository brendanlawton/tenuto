# Tenuto — Agent Guidelines

## Project Structure

This is a monorepo. All platform clients and the shared core library live here.

| Directory  | Platform              | Language    | Status  |
|------------|-----------------------|-------------|---------|
| `api/`     | Laravel API           | PHP 8.5     | Active  |
| `web/`     | Vue 3 SPA             | TypeScript  | Active  |
| `ios/`     | iOS app               | Swift       | Planned |
| `android/` | Android app           | Kotlin      | Planned |
| `core/`    | Playability assessment core | C++   | Planned |

## Before Starting Work

Read the `AGENTS.md` in the sub-project directory you are working in before writing any code. Those files contain platform-specific package versions, tooling commands, and conventions.

> `api/AGENTS.md` and `api/CLAUDE.md` are auto-generated by Laravel Boost and will be periodically updated. Do not edit them manually — any project-specific PHP/Laravel conventions that go beyond what Boost provides belong here in this file.

## Feature Workflow

Features are built as vertical slices:

1. **Core** — only when assessment logic changes (rare, deliberate)
2. **API** — establish the contract: migration → endpoint → resource → tests
3. **Client** — implement one client at a time against the verified API contract

Port order: web first, then iOS, then Android. Do not build across all three clients simultaneously.

## Repository Conventions
